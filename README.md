-  **Achievement:** Secured 3rd place in the college-level Project-Based Learning (PBL) competition.

**Tech:** Python, Flask, Selenium, BeautifulSoup, WHOIS

#### 🌍 ReliefSync — Intelligent Disaster Resource Allocation and Coordination Platform

An ongoing project focused on coordinating disaster-relief resources, shelters, volunteers, and donations.

-  Focuses on disaster-relief coordination and resource allocation.
- Resource-demand analysis and prediction are planned components.

**Tech:** React, Tailwind CSS, Python, Flask, MySQL, Pandas, Scikit-learn

A Flask-based application that recommends recipes based on ingredients provided by the user.

-  Processes recipe data using Pandas and Scikit-learn.

**Tech:** Python, Flask, Pandas, Scikit-learn

⚡ IoT-Based Smart Energy Waste Detection System

An IoT-based project designed to detect unnecessary energy consumption using motion detection and current monitoring.

- Uses motion and current sensors to monitor energy usage.

- Integrates ESP32 with CircuitDigest Cloud for monitoring and alerts.

- Focuses on reducing energy waste through automated monitoring.

Tech: ESP32, PIR Sensor, ACS712 Current Sensor, CircuitDigest Cloud
